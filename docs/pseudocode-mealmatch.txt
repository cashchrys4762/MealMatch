อัลกอริทึม MealMatch

เริ่ม
    รับ เพศ, อายุ, น้ำหนัก, ส่วนสูง, เป้าหมาย, ระดับกิจกรรม, งบประมาณ

    ถ้า เพศไม่ใช่ชายหรือหญิง
       หรือ อายุไม่อยู่ในช่วง 10 ถึง 100
       หรือ น้ำหนักไม่อยู่ในช่วง 20 ถึง 300
       หรือ ส่วนสูงไม่อยู่ในช่วง 50 ถึง 250
       หรือ งบประมาณ < 0
       หรือ เป้าหมายไม่ถูกต้อง
       หรือ กิจกรรมไม่ถูกต้อง แล้ว
        แสดงข้อความข้อผิดพลาด
        กลับไปรับข้อมูลใหม่
    จบถ้า

    BMI ← น้ำหนัก / (ส่วนสูงเป็นเมตร)^2
    ถ้า BMI < 18.5 แล้ว
        สถานะ ← "ผอม"
    มิฉะนั้นถ้า BMI < 23 แล้ว
        สถานะ ← "สมส่วน"
    มิฉะนั้น
        สถานะ ← "ท้วม"
    จบถ้า

    ถ้า เพศ = "ชาย" แล้ว
        BMR ← 10*น้ำหนัก + 6.25*ส่วนสูง - 5*อายุ + 5
    มิฉะนั้น
        BMR ← 10*น้ำหนัก + 6.25*ส่วนสูง - 5*อายุ - 161
    จบถ้า

    TDEE ← BMR * ตัวคูณกิจกรรม
    ถ้า เป้าหมาย = "ลดน้ำหนัก" แล้ว
        แคลอรีวัน ← TDEE - 500
    มิฉะนั้นถ้า เป้าหมาย = "เพิ่มน้ำหนัก" แล้ว
        แคลอรีวัน ← TDEE + 500
    มิฉะนั้น
        แคลอรีวัน ← TDEE
    จบถ้า
    แคลอรีมื้อ ← แคลอรีวัน / 3

    ถ้า งบประมาณ < 40 แล้ว
        รายการ ← เมนูราคา < 40
    มิฉะนั้นถ้า งบประมาณ ≤ 100 แล้ว
        รายการ ← เมนูราคา 40 ถึง 100
    มิฉะนั้น
        รายการ ← เมนูราคา > 100
    จบถ้า

    ถ้า เป้าหมาย = "เพิ่มน้ำหนัก" แล้ว
        รายการ ← เมนูที่แคลอรี ≥ แคลอรีมื้อ
        เรียงแคลอรีจากมากไปน้อย
    มิฉะนั้น
        รายการ ← เมนูที่แคลอรี ≤ แคลอรีมื้อ
    จบถ้า

    ถ้า (สถานะ = "ผอม" และ เป้าหมาย = "ลดน้ำหนัก")
       หรือ (สถานะ = "ท้วม" และ เป้าหมาย = "เพิ่มน้ำหนัก") แล้ว
        คำเตือน ← "เป้าหมายอาจไม่เหมาะสม"
    มิฉะนั้น
        คำเตือน ← ค่าว่าง
    จบถ้า

    ถ้า รายการ = ว่าง แล้ว
        แสดง "ไม่พบเมนูที่เหมาะสม"
    มิฉะนั้น
        แสดง BMI, สถานะ, BMR, TDEE, แคลอรีวัน, แคลอรีมื้อ
        สำหรับแต่ละ เมนู ใน รายการ ทำ
            แสดง ชื่อ, ราคา, แคลอรี, รูป
        จบสำหรับ
        ถ้า คำเตือน ≠ ค่าว่าง แล้ว
            แสดง คำเตือน
        จบถ้า
